# KATHYA Mobile AI Agent

KATHYA AI mobile MVP — **Speak. Understand. Act.**

## Run

```bash
npm install
npx expo start
```

Open with Expo Go or an Android/iOS simulator.

## V1 foundation
- Premium KATHYA onboarding
- AI Agent home and quick actions
- Voice conversation UI
- Chat UI
- Tasks
- Agent library

Next: authentication, persistent database, realtime AI/voice backend, integrations, activity, settings and billing.
